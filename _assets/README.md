# _assets — מברק חברתי תשפ"ז

נכסי העבודה של המהלך. לא נועד לצפייה כדף אינטרנט.

## קבצים
- `gantt.json` — תכני לוח הגאנט לכל החודשים: מועדים, ערכות וקישורים, צבעי חודשים, קישורי המרחבים.
- `gen.py` — מחולל כרטיסי המברק (1080×1080). מקבל קובץ spec בפורמט JSON.
- `pdf.py` — בניית ה-PDF של המכתב החודשי מתוך קובץ HTML.
- `letter_template.html` — תבנית המכתב (הגרסה האחרונה: כסלו).
- `letter_cheshvan.html` — מכתב חשוון, לייחוס.
- `heebo.css` — פונט Heebo כ-base64. נדרש כי הסביבה חוסמת את Google Fonts.
- `logo.b64` — לוגו מפתח הל"ב.
- `paskol.b64` — סימן הלב של הפ"סקול החברתי.
- `ico_shonut.b64` — אייקון ערך השונות.

## חסר
אייקוני עשרת הערכים האחרים. יש רק שונות.

- רק ממקור: גאנט, פורטל מפתח הל"ב, אתר הפ"סקול. לא להמציא ולא לנחש.
- שכבות גיל רק לפי מה שכתוב בדף המקור.
- בלי מקף ארוך.
- אייקונים במשורה.
- מועדים לפי סדר כרונולוגי.
