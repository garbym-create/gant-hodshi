# מכתב חודשי לצוותי החינוך: הוראות הכנה

תיקייה זו מכילה לכל חודש שני קבצים: `<חודש>.html` (הדף להטמעה) ו-`<חודש>.pdf` (להורדה).
שמות החודשים באנגלית, כמו בשאר האתר: tishrei, cheshvan, kislev, tevet, shvat, adar, nisan, iyar, sivan, tamuz.

כתובת הדף: `https://garbym-create.github.io/gant-hodshi/michtav/<חודש>.html`

## מה מקבלים ממרי בכל חודש

1. **טקסט המכתב** (וורד, דרייב, גוגל דוקס או הדבקה בצ'אט). מעתיקים מילה במילה, בלי לערוך ובלי להשלים.
2. **קישורים לערכות** שמוזכרות בטקסט. ערכה בלי קישור מסומנת "(בקרוב)" ומעדכנים כשמגיע קישור.
3. **אייקון הערך** (האיור בעיגול בראש הדף).
   - **פתוח:** עדיין לא ידוע מאיפה מגיעים האייקונים. לשאול את מרי ולעדכן כאן.

## מה לוקחים מהאתר עצמו

- **צבע החודש:** מתוך `peilut/<חודש>.html`, הצבע שליד הכותרת "ערך החודש".
  צבע החודש במכתב נלקח מצבע החודש בלוח הגאנט בקנבה (עמוד החודש הלועזי): אוקטובר `#C87830`, נובמבר `#FFE365`, דצמבר `#7FBF4D`. כשהצבע בהיר, הטקסט בפס העליון כהה (`#4A3A05`) ולא לבן.
- **ערך החודש:** מאותו מקום. לבדוק שהוא תואם לטקסט המכתב, ואם לא, להתריע ולא לבחור לבד.

## בניית הדף

1. מעתיקים את `kislev.html` לקובץ החודש החדש. זו התבנית.
2. מחליפים רק את מה שמשתנה:
   - שם החודש והשנה (`.heb`) והחודש הלועזי (`.lat`). בחשוון נכתב "אוקטובר 2026", כלומר החודש הלועזי שבו רוב החודש העברי.
   - שם הערך (`.value`) ואייקון הערך (`.vicon`, תמונה מוטמעת).
   - צבעי החודש, כולם ב-`:root` בתחילת ה-CSS, כולם מאותה משפחת צבע:
     - `--c` צבע החודש (הפס העליון)
     - `--deep` גוון כהה (פתיח, שם החותמת)
     - `--mid` גוון בינוני (ימי לוח וקישורים ב-PDF)
     - `--uline` גוון בהיר (קו מתחת לקישורים ב-PDF)
     - `--line`, `--tint` גוונים בהירים מאוד (קווים ורקע באתר)
     - `--deep` במצב כהה (בבלוק `prefers-color-scheme:dark`, פעמיים)
     בחשוון: `#C87830` / `#8a4a16` / `#a8601f` / `#e3bf99` / `#EADFD2` / `#FDF6EE` / כהה `#e8a35e`.
     **אסור להשאיר אף אחד מהם בכתום של חשוון.**
   - תוכן `<main>`: פתיחה, פסקאות, ימי לוח (`<span class="hl">`), קישורים לערכות, "בחודש הבא".
   - קישור כפתור ה-PDF בתחתית: `href="<חודש>.pdf"`.
3. לא לגעת בחתימות, בפוטר ובמבנה, אלא אם מרי ביקשה.

## יצירת ה-PDF

```
python michtav/make_pdf.py <חודש>
```

**העיצוב הקבוע הוא עיצוב א'** (נבחר על ידי מרי ב-29/10/2026, בכסלו): `print-a.css`. בלי קו מעל "מאחלות לכולנו".
עיצוב ב' (`print.css`, המקורי של חשוון) נשאר רק לחשוון: `python michtav/make_pdf.py cheshvan b`.
**תבנית לחודש חדש: `kislev.html`**, לא `cheshvan.html`.

הסקריפט מסיר את כפתור ההורדה, מוסיף את `print.css` ומדפיס עם Chrome לעמוד A4 אחד.
**לא לאלתר הגדרות הדפסה.** ההגדרות משוחזרות במדויק מה-PDF-ים המקוריים, ומרי שמה לב כשהעיצוב השתנה.
הסקריפט עוצר אם יצא יותר מעמוד, או אם הטקסט מגיע לפוטר (העמוד בגובה קבוע, אז טקסט ארוך לא עובר לעמוד שני אלא נעלם).
מכתב חשוון משאיר רק כשורה וחצי פנויה. אם מכתב ארוך מדי: לעצור ולהציע למרי אפשרויות (קיצור, הקטנה קלה), לא להקטין לבד.

## בדיקות לפני שאומרים "סיימתי"

- ה-PDF: עמוד אחד, כל הקישורים לחיצים, השוואה צד לצד מול החודש הקודם.
- הדף ברוחב 375 פיקסלים: בלי גלילה לרוחב, האייקון והכותרת תקינים.
- כל הקישורים לערכות עובדים (מחזירים 200).

## העלאה

```
git add michtav && git commit && git push
```

ההתחברות לגיטהאב שמורה במחשב, אין צורך לבקש ממרי לדחוף.
אחרי הדחיפה לוקח לגיטהאב כדקה לעדכן. עד אז הכתובת מחזירה 404 או את הגרסה הישנה.
דפדפנים ואתרים מטמיעים שומרים עותק עד 10 דקות. אם מרי רואה גרסה ישנה: `Ctrl+F5`, או להוסיף `?v=2` לכתובת בהטמעה.

## כללי עבודה

- עברית, בלי מקף ארוך.
- כל מה שלא נמצא במקור (קישור חסר, אייקון חסר, ערך לא תואם) מציינים במפורש ולא משלימים בשקט.
- שינוי קטן (קישור, מילה) = לשנות רק אותו, ולהדפיס PDF מחדש עם הסקריפט.
